# Problem CJ-058 — Employee Class

## Difficulty

Easy–Medium — 10–15 minutes

## Topic

OOP

## Subtopic

Class & Object

## Objective

Create an Employee class, create an object, store employee details, and display them.

## Problem Statement

Create an Employee class with the following fields:

- id
- name
- salary

Take employee details from the user, create an Employee object, store the entered values in the object, and display the employee details.

## Rules

- Create a separate Employee class.
- Create an object using new.
- Store the values in the object's fields.
- Access the fields through the object.
- Use Scanner.
- Do not use a constructor yet.
- Do not use getters/setters yet.
- Do not use inheritance or interfaces.

## Example

Input:

101
Gaurav
50000

Expected Output:

===== Employee Details =====
ID: 101
Name: Gaurav
Salary: 50000.0

## Constraints

- Use Scanner.
- Use a separate Employee class.
- Use new to create the object.
- Use instance variables.
- No constructor.
- No getters/setters.
- No inheritance.
- No interface.
- No collections.

## Learning Outcome

Understand the basic relationship between a class and an object and how instance variables are accessed through an object.
