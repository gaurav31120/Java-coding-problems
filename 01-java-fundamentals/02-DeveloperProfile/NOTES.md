## Interview Questions & Answers

### 1. What is a variable in Java?

A variable is a named memory location used to store a value of a particular data type.

### 2. What is the difference between int and Integer?

`int` is a primitive data type, while `Integer` is the wrapper class for `int`.

### 3. What is the difference between double and Double?

`double` is a primitive data type, while `Double` is the wrapper class for `double`.

### 4. Which should you generally prefer: double or Double?

Prefer primitive `double` when you don't need an object. `Double` is used when an object is required.

### 5. What naming convention is used for Java variables?

Java variables normally follow camelCase.

Example:

String firstName = "Alex";
double totalSalary = 50000.0;
