# Problem CJ-002 — Developer Profile

## Difficulty

Easy

## Topic

Java Fundamentals

## Subtopic

- Variables
- Data Types
- Variable Declaration
- System.out.println()

## Objective

Practice declaring variables using appropriate data types and printing their values.

## Problem Statement

Write a Java program that declares variables for:

- Name
- Age
- Company
- Experience
- Role

Print all the information in a readable format.

## Example Output

Name: Alex
Age: 25
Company: TechCorp
Experience: 2.5 years
Role: Software Developer

## Requirements

- Create a class named `DeveloperProfile`.
- Declare variables for all five pieces of information.
- Use appropriate Java data types.
- Print each value using `System.out.println()`.
- Do not use `Scanner`.
- Do not use loops.
- Do not create additional methods.

## Learning Outcome

After completing this problem, you should understand:

- How to declare variables.
- How to choose basic data types.
- How to store text and numeric values.
- How to print variable values.
