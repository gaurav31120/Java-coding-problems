## Interview Questions & Answers

### 1. What are arithmetic operators in Java?

Arithmetic operators are used to perform mathematical operations such as addition, subtraction, multiplication, division, and modulus.

### 2. What is the difference between + and -?

`+` performs addition, while `-` performs subtraction.

### 3. Can variables be used in arithmetic expressions?

Yes. Java allows variables of compatible numeric types to be used in arithmetic expressions.

### 4. What happens when two int values are added?

The result is also an `int`, provided the calculation does not exceed the range of the `int` data type.

### 5. What is an expression in Java?

An expression is a combination of values, variables, and operators that produces a result.

Example:

int netSalary = salary + bonus - tax;
