# Problem CJ-003 — Salary Calculator

## Difficulty

Easy

## Topic

Java Fundamentals

## Subtopic

- Variables
- Arithmetic Operators
- Data Types
- Basic Calculations

## Objective

Practice storing numeric values in variables and performing arithmetic calculations.

## Problem Statement

Write a Java program that calculates an employee's net salary.

Given:

- Basic Salary = 30000
- Bonus = 5000
- Tax = 3000

Calculate and print the net salary.

## Formula

Net Salary = Basic Salary + Bonus - Tax

## Expected Output

Basic Salary: 30000
Bonus: 5000
Tax: 3000
Net Salary: 32000

## Requirements

- Create a class named `SalaryCalculator`.
- Store the salary values in variables.
- Calculate the net salary.
- Print all values clearly.
- Use appropriate data types.
- Do not use `Scanner`.
- Do not use loops.
- Do not use `if-else`.

## Learning Outcome

After completing this problem, you should understand:

- How to store numeric values in variables.
- How to perform arithmetic operations.
- How to calculate a result using multiple variables.
- How to print calculated values.
