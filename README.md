# Java Coding Problems

A structured hands-on coding repository to learn and practice Java from fundamentals to advanced concepts.

## Goal

Build strong Java fundamentals, problem-solving skills, and interview readiness through coding practice.

## Topics Covered

- Java Fundamentals
- Data Types
- Operators
- Conditions & Loops
- Methods
- Arrays
- Strings
- OOP
- Wrapper Classes, Enums & Generics
- Collections Framework
- Java 8
- Exception Handling
- File I/O
- Multithreading
- Java Internals
- Interview Challenges

## Problem Structure

Each problem contains:

- `Problem.java` — Solution code
- `PROBLEM.md` — Problem statement and requirements
- `Notes.md` — Concepts learned and interview questions & answers


## Progress

See [`PROBLEMS.md`](PROBLEMS.md) for the complete problem list and progress.

## Practice Approach

1. Understand the problem.
2. Write the solution independently.
3. Test the code.
4. Review the concepts.
5. Revise interview questions.
6. Commit the solution to GitHub.
