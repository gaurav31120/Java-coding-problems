# Problem CJ-012 — Number Digit Analyzer

## Difficulty

Medium — 15–20 Minute Interview Practice

## Topic

Loops

## Subtopic

while loop

## Objective

Build a number digit analyzer using a while loop.

## Problem Statement

Take an integer from the user and calculate:

- Number of digits
- Sum of digits
- Product of digits
- Reverse of the number

## Rules

1. Use a while loop to process the digits.
2. Handle a single-digit number correctly.
3. Handle 0 correctly.
4. Construct the reverse mathematically.
5. Do not convert the number to a String.

## Requirements

- Use Scanner.
- Use a while loop.
- Use arithmetic operators.
- Use % and /.
- Do not use String conversion.
- Do not use arrays.
- Do not use another loop.
- Do not create additional methods.

## Example

Input:

Enter number: 482

Expected Output:

===== Number Analysis =====
Number: 482
Digit Count: 3
Digit Sum: 14
Digit Product: 64
Reverse: 284

## Test Cases

### Test Case 1

Number: 482

Expected:

Digit Count: 3
Digit Sum: 14
Digit Product: 64
Reverse: 284

### Test Case 2

Number: 7

Expected:

Digit Count: 1
Digit Sum: 7
Digit Product: 7
Reverse: 7

### Test Case 3

Number: 120

Expected:

Digit Count: 3
Digit Sum: 3
Digit Product: 0
Reverse: 21

### Test Case 4

Number: 0

Expected:

Digit Count: 1
Digit Sum: 0
Digit Product: 0
Reverse: 0

## Learning Outcome

Practice while loops, digit extraction using %, digit removal using /, counters, accumulators, and mathematical number reversal.
