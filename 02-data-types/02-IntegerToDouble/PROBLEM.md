# Problem CJ-005 — Integer to Double

## Difficulty

Medium

## Topic

Type Casting

## Subtopic

- Widening Type Casting
- Implicit Casting
- int → double

## Objective

Practice converting an `int` value into a `double` using implicit widening type casting.

## Problem Statement

Write a Java program that stores an integer value and converts it into a `double` using implicit type casting.

Use:

```java
int value = 100;
```

Print both the integer and converted double value.

## Expected Output

Integer: 100
Double: 100.0

## Requirements

- Create a class named `IntegerToDouble`.
- Declare an `int` variable with value `100`.
- Convert the `int` value to `double`.
- Do not use explicit casting such as `(double)`.
- Print both values.
- Do not use `Scanner`.
- Do not use loops.

## Learning Outcome

After completing this problem, you should understand:

- What widening type casting is.
- What implicit type casting is.
- How an `int` can be automatically converted to `double`.
