# Problem CJ-006 — Double to Integer

## Difficulty

Medium

## Topic

Type Casting

## Subtopic

- Narrowing Type Casting
- Explicit Casting
- double → int

## Objective

Practice converting a `double` value into an `int` using explicit narrowing type casting.

## Problem Statement

Write a Java program that stores a decimal value and converts it into an `int` using explicit type casting.

Use:

```java
double value = 125.75;
```

Print both the original `double` value and the converted `int` value.

## Expected Output

Double: 125.75
Integer: 125

## Requirements

- Create a class named `DoubleToInteger`.
- Declare a `double` variable with value `125.75`.
- Convert it to `int`.
- Use explicit casting.
- Print both values.
- Do not use `Scanner`.
- Do not use loops.

## Learning Outcome

After completing this problem, you should understand:

- What narrowing type casting is.
- What explicit type casting is.
- How `double` is converted to `int`.
- What happens to the decimal part during narrowing.
