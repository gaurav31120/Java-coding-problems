## Key Learning

Java has 8 primitive data types:

- Integer types: byte, short, int, long
- Floating-point types: float, double
- Character type: char
- Boolean type: boolean

A `float` literal normally requires the `f` suffix.

Example:

```java
float price = 10.5f;
```

## Interview Questions & Answers

### 1. What are the 8 primitive data types in Java?

`byte`, `short`, `int`, `long`, `float`, `double`, `char`, and `boolean`.

### 2. What is the difference between float and double?

`float` uses 32 bits, while `double` uses 64 bits and provides greater precision.

### 3. Why do we use `f` after a float value?

Decimal literals are treated as `double` by default. The `f` suffix tells Java that the literal should be treated as a `float`.

### 4. What is the difference between char and String?

`char` stores a single character, while `String` represents a sequence of characters.

### 5. Is boolean a numeric data type?

No. `boolean` represents either `true` or `false`.

### 6. Which primitive data type is commonly used for whole numbers?

`int` is commonly used for whole-number values.
