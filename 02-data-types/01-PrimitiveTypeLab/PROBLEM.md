# Problem CJ-004 — Primitive Type Lab

## Difficulty

Easy

## Topic

Data Types

## Subtopic

- Primitive Data Types
- Variable Declaration
- Variable Initialization

## Objective

Practice declaring and printing all 8 primitive data types in Java.

## Problem Statement

Write a Java program that declares all 8 primitive data types and prints their values.

Use:

- byte → 10
- short → 100
- int → 1000
- long → 10000
- float → 10.5
- double → 100.50
- char → A
- boolean → true

## Expected Output

Byte: 10
Short: 100
Int: 1000
Long: 10000
Float: 10.5
Double: 100.5
Char: A
Boolean: true

## Requirements

- Create a class named `PrimitiveTypeLab`.
- Declare all 8 primitive data types.
- Use the correct data type for each value.
- Print every variable.
- Do not use `Scanner`.
- Do not use arrays.
- Do not use loops.

## Learning Outcome

After completing this problem, you should understand:

- The 8 primitive data types in Java.
- How to declare primitive variables.
- How to initialize primitive variables.
- The difference between integer, decimal, character, and boolean types.
