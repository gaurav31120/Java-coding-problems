# Problem 31 — Reverse Array

## Difficulty

Easy → Medium — 15–20 minutes

## Topic

Arrays

## Subtopic

Array reversal, swapping, two-pointer technique

## Objective

Reverse an array in-place without creating another array.

## Problem Statement

Create an integer array containing:

10
20
30
40
50

Reverse the array in-place.

Before:

10 20 30 40 50

After:

50 40 30 20 10

## Expected Output

===== Original Array =====

10
20
30
40
50

===== Reversed Array =====

50
40
30
20
10

## Requirements

- Use an int[].
- Reverse the array in-place.
- Use two pointers.
- Use swapping.
- Use a temporary variable.
- Do not create a second array.

## Bonus

Try implementing the reversal using a traditional for loop.

## Learning Outcome

Understand array swapping, two-pointer traversal, in-place modification, and how to reverse an array without extra array storage.
