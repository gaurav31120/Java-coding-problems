# Problem 29 — Array Sum/Average

## Difficulty

Easy → Medium — 15–20 minutes

## Topic

Arrays

## Subtopic

Sum, average, traversal

## Objective

Calculate the total and average of values stored inside an integer array.

## Problem Statement

Create an integer array containing:

50000
75000
45000
90000
60000

Calculate:

1. Total salary
2. Average salary

Use a loop to calculate the total.

## Expected Output

===== Salary Analysis =====

Total salary: 320000
Average salary: 64000.0

## Bonus

Count how many employees earn more than the average salary.

Expected:

Employees above average: 2

## Rules

- Use int[].
- Use a loop.
- Use array.length.
- Store average as double.
- Do not use Streams.
- Do not use ArrayList.
- Do not manually calculate the sum.

## Learning Outcome

Understand how to traverse an array, accumulate values, calculate an average, and handle integer-to-double conversion.
