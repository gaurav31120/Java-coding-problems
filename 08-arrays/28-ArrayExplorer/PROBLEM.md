# Problem 28 — Array Explorer

## Difficulty

Easy — 15–20 minutes

## Topic

Arrays

## Subtopic

Array creation, indexing, traversal, length

## Objective

Learn how to create, access, traverse, and inspect the length of an array.

## Problem Statement

Create an integer array containing:

50000
75000
45000
90000
60000

Perform the following operations:

1. Print every salary.
2. Print each index with its corresponding salary.
3. Print the total number of employees.
4. Print the first salary.
5. Print the last salary.

## Expected Output

===== Salaries =====

50000
75000
45000
90000
60000

===== Index + Salary =====

Index 0 -> 50000
Index 1 -> 75000
Index 2 -> 45000
Index 3 -> 90000
Index 4 -> 60000

Total employees: 5

First salary: 50000

Last salary: 60000

## Rules

- Use int[].
- Use a traditional for loop.
- Use array.length.
- Use array indexing.
- Do not use ArrayList.
- Do not use Streams.
- Do not manually print every salary.
- Do not hard-code the last index.

## Bonus

Print the array in reverse order.

Expected:

60000
90000
45000
75000
50000

## Learning Outcome

Understand array creation, zero-based indexing, traversal using for loops, array length, first element access, and last element access.
