# Problem 30 — Max & Min

## Difficulty

Easy → Medium — 15–20 minutes

## Topic

Arrays

## Subtopic

Maximum and minimum

## Objective

Find the maximum and minimum values in an integer array using a loop.

## Problem Statement

Create an integer array containing:

50000
75000
45000
90000
60000

Find:

1. Maximum salary
2. Minimum salary

Use a loop to find both values.

## Expected Output

===== Salary Analysis =====

Maximum salary: 90000
Minimum salary: 45000

## Bonus

Find the index of the maximum and minimum salary.

Expected:

Maximum salary: 90000
Maximum salary index: 3

Minimum salary: 45000
Minimum salary index: 2

## Rules

- Use int[].
- Use a loop.
- Use if conditions.
- Initialize max and min using the first element.
- Do not use Arrays.sort().
- Do not use Streams.
- Do not use ArrayList.
- Do not manually determine the answer.

## Learning Outcome

Understand how to find maximum and minimum values by maintaining and updating variables while traversing an array.
